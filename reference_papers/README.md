# Reference papers

Real, open-access papers pulled for this project's research report — read for actual
academic writing conventions (how professionals phrase results, hedge claims, and
structure sections), not copied from. Also useful as genuine literature-review sources
since several are directly cited in the report.

1. **BrainDINO** (2026) — foundation model pretrained on 6.6M brain MRI slices;
   reference point for AD-vs-CN performance without shortcut inflation.
2. **Skull-Stripping Induces Shortcut Learning** (2025, Tinauer et al.) — shows a
   common preprocessing step can itself become a spurious shortcut ("Clever Hans"
   effect); model for how to phrase cautionary/limitation findings.
3. **3D CNN, Leakage-Aware Subject-Level Evaluation** (2026) — closest methodological
   sibling to this project's own leakage-avoidance approach.
4. **Cross-Cohort Generalizability** (2020, Ansart et al.) — shows models validated
   on one cohort often fail to reproduce accuracy externally.
5. **CNN on T1-weighted MRI for AD** (2020, Scientific Reports) — closest genre match
   to a standard multi-model CNN comparison paper.
